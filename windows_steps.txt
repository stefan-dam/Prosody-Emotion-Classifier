1) Create and activate a Python environment, then install dependencies:
   - `python -m venv venv`
   - PowerShell: `\.\venv\Scripts\Activate.ps1`
     Command Prompt: `venv\Scripts\activate.bat`
   - `python -m pip install -r requirements.txt`

2) Install CUDA-enabled PyTorch for your CUDA version (so GPU is used), then verify:
   - `python -c "import torch; print(torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU only')"`

3) Put datasets under `data/`:
   - RAVDESS: `data/RAVDESS/Actor_01/*.wav`, `data/RAVDESS/Actor_02/*.wav`, ...
   - CREMAD: `data/CREMAD/*.wav`

4) Build metadata + splits:
   - `python src/make_metadata_ravdess.py`
   - `python src/make_metadata_cremad.py`
   - `python src/make_splits.py RAVDESS --seed 42`
   - `python src/make_splits.py CREMAD --seed 42`

5) Start a fresh run in a dedicated folder `models/new_training` (same training hyperparameters):
   - `python src/train_hubert_cls.py --datasets RAVDESS CREMAD --config configs/hubert_large_4070_new_training.json`
   - This writes checkpoints and model files only under `models/new_training`.

6) Resume if needed:
   - `python src/train_hubert_cls.py --datasets RAVDESS CREMAD --config configs/hubert_large_4070_new_training.json --resume_from_checkpoint models\new_training\checkpoint-2000`
   - Resume is strict pause/resume in this config: optimizer/scheduler/RNG/data-skip states are restored from checkpoint, and training aborts if a checkpoint is incomplete.

7) Evaluate the best (saved) model with ultra-light settings (CPU + small sample):
   - `python src/eval_hubert_cls.py --datasets RAVDESS CREMAD --model_dir "models\new_training" --split val --max_samples 50 --max_seconds 2 --batch_size 1 --device cpu --feature_extractor superb/hubert-large-superb-er`
